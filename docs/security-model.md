# Security Model

## 信任边界

- 浏览器提交的角色、店铺和数量都不可信。
- 服务端从哈希会话令牌恢复用户身份，并建立数据库会话上下文。
- PostgreSQL RLS 默认拒绝，应用层遗漏过滤时仍应阻止跨店访问。
- 浏览器不持有数据库、文件存储或管理员密钥。

## 认证与会话

- 密码使用 Argon2id 加盐哈希。
- 会话令牌由高熵随机数生成，数据库只保存 SHA-256 哈希。
- Cookie 使用 `HttpOnly`、`SameSite=Lax`，生产环境要求 `Secure`。
- 登录按邮箱与来源双重限流；停用用户或提升会话版本会使旧会话失效。
- TOTP 种子加密保存，恢复码不进入仓库。

## 数据与文件

- Excel 在服务端校验大小、类型、模板元数据与业务行。
- 文件名不作为存储路径，原文件使用不可预测对象键并记录哈希。
- 同店铺、同业务类型、同文件哈希不可重复入账。
- 审计日志避免记录密码、完整令牌、密钥和数据库连接串。
